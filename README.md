# TorrServer.MacEdition

Лёгкий и удобный менеджер для запуска **TorrServer MatriX** в системном трее macOS (оптимизирован для Intel Mac и macOS Monterey+).

### Особенности:
- Работает прямо из системного меню (Menu Bar).
- Динамически меняет иконки в зависимости от статуса сервера (Вкл/Выкл/Загрузка).
- Поддержка автозагрузки через системные агенты `LaunchAgents`.
- Проверка обновлений в один клик.
